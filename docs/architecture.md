## 🚀 دورة الحياة للطلب (Request Lifecycle)

```
1. CLIENT REQUEST
   │ POST /api/rooms/admin/all
   │ Header: Authorization: Bearer <token>
   │
   ├─► 2. NGINX
   │      • جدران الحماية (Firewalls)
   │      • معدل التحديد (Rate Limiting)
   │      • إعادة التوجيه (Routing)
   │
   ├─► 3. FASTAPI STARLETTE
   │      • التحقق من المضيف (Host validation)
   │      • معالجة CORS
   │      • تسجيل الطلب
   │
   ├─► 4. DEPENDENCY INJECTION
   │      • get_db() - توصيل البيانات
   │      • get_current_user() - المصادقة
   │      • require_role() - التفويض
   │
   ├─► 5. ROUTE HANDLER
   │      • admin_list_all_rooms()
   │      • التحقق من البيانات
   │      • منطق العمل
   │
   ├─► 6. REPOSITORY LAYER
   │      • RoomRepository.get_all()
   │      • استعلام قاعدة البيانات
   │
   ├─► 7. DATABASE
   │      • SELECT * FROM rooms
   │      • معالجة البيانات
   │
   ├─► 8. CACHE (Redis) [اختياري]
   │      • التحقق من الكاش
   │      • حفظ النتيجة
   │
   └─► 9. RESPONSE
      • تحويل إلى JSON
      • رمز HTTP
      • إرسال إلى العميل
```
